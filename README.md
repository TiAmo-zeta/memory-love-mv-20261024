# 把回忆拼好给你 · 情侣动画 MV

原创 Canvas 情侣故事，包含八章、42 个镜头，按提供的 DJ 音频节拍编排。

## 手机观看

打开 GitHub Pages 地址，点击播放即可。支持竖屏、横屏、触控进度条、章节跳转和影院模式。

手机浏览器需要首次手动点击播放。原生全屏不支持时会自动切换为网页影院模式。

手机默认使用 30 帧和自适应画布，静态背景、相片与拼图共用缓存；音乐时间始终决定动画进度。高级设置里的“播放画质”可切换“更流畅”或“高清”。

## 文件

- `index.html`：动画、播放器、节拍与能量数据。
- `music.mp3`：随网页播放的音频，单独加载以加快页面显示。
- `.nojekyll`：GitHub Pages 静态发布标记。

导入的音频和歌词仅由浏览器本地读取，页面没有登录、统计或上传接口。

## 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支的根目录。
